# German Dictionary

German (Germany) spell-check dictionary: adds Deutsch to Settings → Editor → Spell Check, compound words included (Fußball, Rechtschreibprüfung). Hunspell data comes from [igerman98](https://www.j3e.de/ispell/igerman98/index_en.html) (GPL-2.0, see LICENSE) and ships as package assets, loaded lazily through `ctx.assets` only when the language is selected.

Needs Glyph 0.28.0 or later, whose spell checker understands the compound rules this dictionary relies on.

- **Permissions**: none
- **Sandbox**: yes
- **Package**: [release zip](https://github.com/glyph-md/plugins/releases/tag/com.glyph.dictionary-de-v1.0.0)
