# Spanish Dictionary

Spanish spell-check dictionary: adds Español to Settings → Editor → Spell Check. Hunspell data comes from [RLA-ES](https://github.com/sbosio/rla-es), a general Spanish dictionary not tied to one country, distributed here under MPL-1.1 (see LICENSE). It ships as package assets, loaded lazily through `ctx.assets` only when the language is selected.

- **Permissions**: none
- **Sandbox**: yes
- **Package**: [release zip](https://github.com/glyph-md/plugins/releases/tag/com.glyph.dictionary-es-v1.0.0)
